# DreamTown Admin Panel

This is the admin interface for DreamTown, a city-building web game. This panel is designed for administrators to monitor players, manage buildings, and perform system-level tasks.

## Features
- Admin-only access to special city (AdminTown)
- Full access to all building upgrades
- Firebase integration (optional)
- Custom UI with animation and night/day system

## How to Use
1. Upload to web hosting (e.g., Netlify).
2. Open `adminTown.html` in a browser.
3. Integrate with Firebase for login & control if required.
