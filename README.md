# DreamTown - Web Game Project

DreamTown is a fantasy city-building browser game using Firebase for auth, Realtime Database for sync, and Netlify for deployment.

## Features
- Player login/register system
- Building upgrades
- Farming system
- Trading and rare item drops
- Admin panel and dashboard

## Tech Stack
- HTML/CSS/JS
- Firebase Auth & Database
- Netlify Hosting

## Setup
1. Clone this repo
2. Replace `firebase/config.js` with your Firebase config
3. Open `index.html` to test locally
